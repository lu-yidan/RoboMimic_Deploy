# G1 连续横杆攀爬墙

本场景按机器人净爬升约2米布置。2米不是墙的总高：起始手杆高1.55米，目标手杆高3.55米，需要约3.8米高的墙体。沿用前一场景的5度倾角，越高墙面越向机器人前方的正X方向退让。

## 场景尺寸

| 项目 | 当前值 |
| --- | --- |
| 目标竖直爬升量 | 2.00 m |
| 墙体高 / 宽 / 厚 | 3.80 / 1.70 / 0.06 m |
| 横杆数量 / 高度间距 | 14排 / 0.25 m |
| 横杆半径 / 轴向端点跨度 | 0.015 / 1.44 m |
| 杆心相对墙前表面的水平外伸距离 | 0.35 m |
| 横杆高度范围 | 0.30–3.55 m |
| 起始脚杆 / 手杆 | 第0排0.30 m / 第5排1.55 m |
| 目标脚杆 / 手杆 | 第8排2.30 m / 第13排3.55 m |

每排贯通横杆均有左右支臂、斜撑及通高安装轨。支臂、斜撑、轨道与墙体的几何相接关系已检查。墙面、横杆和支架均为固定碰撞几何；其连接不代表已完成螺栓、焊缝或材料强度设计。橙色标识初始脚杆和手杆，绿色标识最高目标手杆。

## 足部与初始姿态

移除旧的脚下平台。原来的四角足底接触球不能表达脚掌中部踩细杆，因此在此场景中改为每脚一个近似平面足底碰撞盒，保留原脚部质量和惯量。足底平面在踝部局部Z=-35 mm，原脚部可视网格最低点约-35.4 mm，两者存在约0.4 mm几何近似差异。摩擦系数0.8是假设值，尚未标定。

初始双脚以前掌区域踩在第0排横杆上，接触模型预压0.2 mm。膝关节弯曲0.2 rad，以避免旧下蹲姿态与中间横杆相撞；双臂通过逆运动学对齐第5排横杆。黑色V2钩爪沿用已完成的仿真装配，腕部转接件仍为琥珀色占位，钩爪刚性连接仍是仿真假设。

## 生成与打开

从仓库根目录执行。需要先存在V2装配源场景 `outputs/g1_hook_v2_mount_v2`；其生成方法见 `cad/g1_hook_v2/README.md`。

```powershell
.\.venv\Scripts\python.exe scenes\climb_wall\build_scene.py
.\.venv\Scripts\python.exe scenes\climb_wall\check_scene.py
.\.venv\Scripts\python.exe -X utf8 -u deploy_mujoco\deploy_mujoco.py --config-name mujoco_climb_wall_2m hydra.job.chdir=false
```

默认输出为`outputs/climb_wall_2m_v3`。生成器拒绝覆盖已有目录；重新生成请指定新的`--out`，并更新查看配置的路径。尺寸参数位于`parameters.json`，模型、初始姿态、杆位清单和校验报告均在输出目录。

按1看整墙、2看机器人、3看双钩、4看双脚、5看侧面；A切换转接件占位，C切换碰撞代理显示，R复位。此模式没有物理时间推进，不执行策略或真机通信。

## 已验证与未验证

- MuJoCo成功编译，保留29个执行器、浮动基座，不加固定机器人约束。
- 140项杆、支架、轨道、墙面连接检查通过。
- 初始姿态及沿杆列向上平移的8个静态姿态，共9个离散位置，覆盖2米高差；活动碰撞检测仅发现预期足底接触，没有其他超过0.01 mm的穿透。
- 这些平移姿态仅用于检查场景覆盖范围，**不是运动轨迹，不证明换手换脚可达、站立稳定或成功爬升**。相邻机器人刚体仍遵循原模型碰撞过滤。

下一步在此场景实现一排25厘米的受控换手、抬脚、载荷转移，再扩展到连续攀爬。原训练环境和旧策略未迁移到此场景，不能直接沿用旧目标观测或把本次场景检查当成策略通过。
