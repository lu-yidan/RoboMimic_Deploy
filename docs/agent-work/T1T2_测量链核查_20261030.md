# T1/T2 结论：测量链是好的，但我的两个前提都错了（2026-10-30 夜间）

> 今晚的目标只有一个：**让"训练有没有用"这句话成立**。
> 要做到这点，先得确认测量链可信。查完之后发现：**测量链没问题，是我对系统的两个理解错了。**

---

## 一、异常的解释：不是测量链坏了，是两次训练本来就是同一次

之前观察到：oracle 微调的 checkpoint `e8f731a8` 与 blind 的 `101d987a` 不同，但 24 工况的闭合**逐位相同**。

逐层查证：

| 检查 | 结果 |
|---|---|
| 评估时 arm 里装的策略 | 各自正确（sha 与各自 run 一致） |
| actor 权重逐张量比对 | **max\|Δw\| = 0.000e+00（全部相同）** |
| 同一观测下的动作 | **完全相同**（5 个采样点全部 `array_equal`） |
| 前后缀路由 | 闭合窗口 `obs[105] ≤ 0.3824` → **确实走 suffix** |

**结论：两个 checkpoint 的网络权重完全相同**，sha 差异来自 zip 里的优化器状态/时间戳。
原因是我的 `G1_ORACLE_OBSERVATION` 补丁是**空操作**——见下。

## 二、更正 1：系统本来就用 oracle 几何，不需要我"打开"

三个 manifest 的 `geometry_mode` **全部是 `oracle`**：

```
calibrated_geometry_training_baseline_20261027_v1   geometry_mode=oracle
calibrated_geometry_ppo131072_20261029_wide125_v1   geometry_mode=oracle
calibrated_geometry_ppo131072_20261029_oracle_v1    geometry_mode=oracle
```

而且 `CalibratedLandingEnv.step` 里就用 `obs[138]`（= `rung_01` 的 z 偏移/0.02）来门控校准偏置：

```python
gain = clip((obs[138] - .625) / .125, 0, 1)     # 位移 <12.5 mm 时 gain=0
```

所以 **"策略看不见杆位"这个说法是错的**。我把它强制成 `mode='oracle'`，等于什么都没做，
于是两次训练是完全相同的配方 + 相同种子 → 相同权重 → 相同轨迹。

**后果**：昨晚那次 131k 步的"oracle 实验"**没有回答任何问题**，它是自己和自己比。
但**不影响**其他结论——"重训 vs 冻结"对比用的是真正不同的策略（`101d987a` vs `799d4d7b`）。

## 三、更正 2：T8 的"投影精确为零"是跨工况敏感性，不是通道断了

`geometry_projection` 是一个 `(136, 12)` 的线性映射，查实际权重：

| 量 | 值 |
|---|---|
| max\|w\| | **0.0222** |
| 非零元素 | **272 / 1632**（正好 2 列） |
| 非零的是哪两列 | `rung_01` 的 **x 和 z**（其余 10 个特征权重为零） |
| 轨迹上几何特征非零列数 | **2** |

所以真实情况是：**策略确实接收并使用杆位信息，但只用 2 个特征、权重只有 0.022（很弱）**。

T8 的"投影为零"是在**跨 24 个工况**做敏感性时得到的——而那 24 个工况的位移差 <0.1 mm，
特征几乎不变，所以"跨工况敏感性 ≈ 0"是必然结果，不能据此推断通道断了。

## 四、这对"RL-ready"的判断意味着什么

原来的判断是"策略盲 → 必须先加感知通路（T10）"。**这个判断要撤回。**

修正后的差距清单：

| 项 | 状态 | 证据 |
|---|---|---|
| 测量链（评估是否用策略输出） | ✅ **可信** | 权重级比对 + 路由静态核实 |
| 观测是否含几何 | ✅ **含**（2/12 特征，权重 0.022） | `geometry_projection` 实际权重 |
| 动作权限 | ⚠️ 上限 1.25×（18.75 mrad）vs 下垂 32.6 mrad | 权限四档曲线 |
| 奖励 | ⚠️ v2 终局裕量未产生增量 | 两次 131k 步对比 |
| **残差的可达杠杆** | ❓ **正在测**（本文件写完后出结果） | `gain_ceiling.py` |
| 工作点 | ⚠️ 距悬崖 0.7 mm | 位移失效曲线 |

**关键的新问题**：如果给满权限的随机残差，闭合的散布就只有 ~0.4 mrad，
那训练拿到的 0.4 mrad **就是天花板本身**，问题不在训练、不在观测、不在奖励，而在**杠杆**。

这条正在跑（4 个噪声 seed × 2 个工况）。
