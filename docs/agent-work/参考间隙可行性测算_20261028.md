# 参考间隙可行性测算（2026-10-28 22:35）

> 目的：在动整条审计链之前，先用**只读**方式确认"把摆动间隙打开"在运动学上是否可行、能开多大。
> 结论：**可行。摆动脚 +8 mm 向上、+4~8 mm 离墙，最小间隙从 −0.2 mm 提升到 +5.3~7.4 mm，且不触发任何关节限位。**

---

## 一、做法

- 参考：当前实际使用的 `outputs/support_retarget_plan_v1/plan.npz`（未修改）
- 窗口：**75–89 s**（抬脚离杆之后、落地之前，共 107 个节点；避开支撑相）
- 操作：对每个节点，用阻尼最小二乘把左脚（`left_ankle_roll_link`）平移到 `(x+dx, z+dz)`，
  关节限制在原生范围内；随后用**碰撞体**（`left_sole_surface`）算它与各横杆的有符号距离。
- 只看 `rung_01`（唯一限制项）。

## 二、结果

| dx 离墙 (mm) | dz 向上 (mm) | 最小间隙 (mm) | 关节限位触发 |
|---|---|---|---|
| −4 | 0 | −1.31 | 0 |
| **0** | **0** | **−0.20**（现状：擦杆） | 0 |
| 0 | 4 | +2.52 | 0 |
| 0 | 8 | +5.28 | 0 |
| 4 | 4 | +3.54 | 0 |
| 4 | 8 | +6.36 | 0 |
| **8** | **8** | **+7.35** | 0 |

- **两个方向都是单调的**：往上抬、往外让，都能增加间隙，可以叠加。
- **所有组合都没有触发关节限位**（107 个节点 × 12 组，0 次）。
- 摆动窗口在 89 s 结束，**终点（99.66 s 之后）完全不受影响** → 端点闭合/抬升不变。

## 三、可以给重建的具体指标

| 参数 | 现状 | 建议 |
|---|---|---|
| 摆动脚抬升 | `swing_clearance = 0.008` | **0.014–0.016**（+6~8 mm） |
| 腿部离杆余量 | `leg_clearance = 0.014` | **0.018–0.020** |
| 目标最小间隙 | −0.2 mm（擦杆） | **≥ +5 mm**，宽裕值 ≥ +7 mm |

> 换算说明：`swing_clearance`/`leg_clearance` 是规划器的参数（米），本次测算给出的是**末端脚位**的
> 等效位移，两者不是同一个量；重建时以"重建后用同一口径实测最小间隙"为准，不要只信参数值。

## 四、这次测算**没有**证明的东西

1. **没有跑动力学**：只证明"几何上摆得开"，没有证明控制器跟得住、接触不失稳。
2. **没有重建整条链**：plan → audit → prefix → policy 都要重做，且旧策略在新参考上是否还能用，未知。
3. **没有做全局碰撞检查**：只查了摆动窗口内左脚与横杆；其余部位/时段需要重建后的 plan 审计覆盖。
