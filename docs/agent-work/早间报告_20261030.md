# 早间报告（2026-10-30）

> 今晚目标：让"训练有没有用"这句话成立，并找出进入 RL 阶段前必须修的东西。
> **结论：动作参数化是瓶颈，不是奖励、不是观测、不是优化预算。**

## 一、头条：三轮"改一个变量"的训练，结论一致

全部 24 工况、全部通过、全部与 blind 1.25× 对比：

| 干预 | 策略移动量 `\|\|Δw\|\|/\|\|w\|\|` | 闭合 mean | 相对 blind |
|---|---|---|---|
| 冻结 1.0×（基线） | — | 38.115 | — |
| 冻结 1.25×（只改权限常量） | — | 37.905 | — |
| 重训 1.25×（原配方） | **0.195%** | 37.905 | ±0.00 |
| 奖励放大 50× | **0.166%** | 38.001 | +0.10 |
| **学习率 ×10 + KL ×5** | **0.985%** | **37.858** | **−0.047** |

**最后一次是决定性的：策略移动量翻了 5 倍（0.195% → 0.985%），闭合只动了 0.047 mrad。**

| 假说 | 检验 | 判定 |
|---|---|---|
| 观测被喂零 | `geometry_mode` 全是 oracle；投影 272 非零 | ❌ 否掉 |
| 奖励太"平" | 稠密项放大 50× 重训 | ❌ 否掉（略差） |
| 优化预算不够 | lr ×10、KL ×5，移动量 ×5 | ❌ 否掉（仅 −0.047） |
| **动作参数化** | 结论落在唯一没被否掉的一项 | ✅ **成立** |

## 二、为什么是动作参数化（三条独立证据）

| 动作变化类型 | 对闭合的影响 |
|---|---|
| 26 维随机噪声（满权限 σ=0.015） | **0.05 mrad** |
| 26 维系统性训练（三组，最大移动量 0.985%） | **0.05–0.4 mrad** |
| **2 维**固定偏移（膝/踝，校准偏置 0→1.0） | **2.3 mrad** |
| 权限常量 1.0→1.25×（等效 2 维） | **0.85 mrad** |

**26 维残差里没有"高杠杆方向"；高杠杆方向是低维的（膝/踝/腰部/抬升）。**

这也解释了为什么三次训练都只学到 0.4 mrad：它在 26 维里能找到的唯一系统性方向，影响就是这么大。

## 三、进入 RL 阶段还差什么（定稿）

| 项 | 状态 | 结论 |
|---|---|---|
| 测量链 | ✅ 可信 | 权重级比对 + 路由静态核实 |
| 观测 | ✅ 含几何（2/12 特征，权重 0.022） | 不是瓶颈 |
| 奖励 | ✅ 不是瓶颈 | 不必再调 |
| 优化预算 | ✅ 已排除 | lr ×10 只值 0.047 mrad |
| **动作参数化** | ❌ **瓶颈** | **必须改成低维、物理对齐的动作空间** |
| 训练工况位置 | ⚠️ 距悬崖 0.7 mm | 训练分布应移到 z ≤ 14 mm，让改进可见 |
| 可分享成果 | ✅ 权限 1.25×（max 40.09→38.84）、摆动抬升 8 mm（物理失败 2→0） | 可直接采纳 |

### 建议的下一步（按代价）

1. **动作空间降到 4–6 维**（膝偏置、踝偏置、腰部前倾、抬升高度、身体前移），
   其余维度锁死。这是把"高杠杆方向"直接变成搜索空间。
   预期：可达范围从 0.4 mrad 提升到 1.5–2.3 mrad（即校准偏置的量级）。
2. **训练分布移到 z ≤ 14 mm**（远离悬崖），让改进不被方差淹没。
3. 上两条做完，再谈"训练能不能稳定产出改进"。
