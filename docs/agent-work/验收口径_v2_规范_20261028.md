# 验收口径 v2（规范）

> 版本：2026-10-28 v2.0
> 取代：v1 中"每周期末关节闭合 < 0.04 rad"作为**硬判据**的条款
> 状态：已批准（2026-10-28），实现见 `.dsh-watch/profile_eval.py`
> 适用范围：G1 双钩+双脚横杆攀爬的周期验收与几何鲁棒性评估

---

## 1. 为什么要改（证据摘要，完整论证见《验收重构提案》）

| 事实 | 数值 | 说明 |
|---|---|---|
| 40 mrad 的来历 | "0.038 过、0.0402 不过" | 见 `docs/baselines/compact_gait_20261009.md`，无物理推导 |
| 成功 8 周期的名义几何闭合 | 25.9–28.2 mrad | 真实部署工况余量 12–14 mrad |
| 成功 8 周期最差角（boundary_07） | 39.898 mrad | 离旧门只差 0.102 |
| 16 个新几何 | 38.0–40.4 mrad | 整体落在"最差角"端 |
| 落在 40±0.5 mrad 内的新工况 | 10/16（62%） | 判据线正好切在分布中间 |

**结论**：旧门是一个拟合出来的代理指标，它把"几何轻微变差"误判为"能力失败"。v2 用物理量判成败，把闭合降级为质量指标。

---

## 2. 判据分层

| 类别 | 指标 | 性质 |
|---|---|---|
| **A. 物理判据** | 抬升、四支撑、承载位置、非预期接触、原生限位、数值有效性 | **决定通过/失败** |
| **B. 姿态质量** | 端点执行器误差、躯干倾斜、末端速度 | **决定通过/失败**（阈值宽松，见 3.2） |
| **C. 收敛质量** | 每周期关节闭合 | **质量指标，不判失败**；35 mrad 预警 |

---

## 3. 指标定义与阈值

### 3.1 物理判据（每周期末最后 2 s，采样 ≥99 点，全部满足）

| 指标 | 定义 | 阈值 |
|---|---|---|
| 抬升 | `max(qpos_z) − qpos_z(起始)`，末段 2 s 内最大值 | 250 ± 10 mm（梯距 25 cm） |
| 四支撑 | 每个支撑组（双手/双脚）的法向力 | 各 > 10 N |
| 承载接触 | 所有接触力 >1 N 的触点 | 必须落在**预定杆**上 |
| 非预期接触 | 非支撑组接触、自碰撞、摆动接触 | 峰值 >1 N 即失败 |
| 原生关节限位 | 关节位置 − 限位 | 不得越界（裕量 ≥ 0） |
| 数值有效性 | 有限状态、无 MuJoCo 警告、力分配成功 | 必须 |

### 3.2 姿态质量（末段 2 s 的峰值）

| 指标 | 阈值 | 依据 |
|---|---|---|
| 端点执行器误差 | < 10 mm | 钩爪开口与杆径的容差（φ30 杆） |
| 躯干倾斜 | < 3° | 姿态可控范围 |
| 末端线速度 / 角速度 / 关节速度 | < 0.01 m/s / 0.1 rad/s / 0.1 rad/s | "停稳"的判定 |

> 注：这些阈值目前沿用 v1，**未重新推导**。它们不是本次争议点（实测 6.0–6.2 mm、0.73°、远低于阈值），
> 但应列入后续复核清单。

### 3.3 收敛质量（不判失败）

```
closure = max over 29 joints | q_endpoint − q_initial |          （末段 2 s 内取最大）
```

- **35 mrad = 预警线**（≈ 名义 28 的 1.25 倍）。越线触发分析，**不判失败**。
- **40 mrad = 旧拟合线**。仅作历史对照，报告里可以出现，**不得作为通过/失败依据**。

## 4. 验收流程

### 4.1 单周期几何鲁棒性剖面（用于评估"这组几何能不能做"）

1. 对每个工况跑**一次**确定性全周期（113.66 s，time-zero，冻结前缀）。
2. 判定：只看 3.1 + 3.2（物理与姿态质量）。
3. 报告：物理通过数 + 闭合的 mean / median / P95 / max + 越 35 mrad 的个数 + 失败清单及原因。
4. **不使用**闭合的二值判定；不同几何之间比较闭合时，用分布统计而不是"过了几个"。

### 4.2 正式验收（用于"能不能爬两米"）

1. **连续 N = 8 周期**，周期之间不做物理重置，状态连续传递。
2. 每一周期都必须满足 3.1 + 3.2。
3. 总抬升 = 8 × 250 mm ± 10 mm。
4. 报告：逐周期抬升、逐周期闭合、最小原生限位裕量、峰值接触力、录像解码结果。

> 单周期剖面是**筛选**，多周期端到端才是**验收**。任何对外结论必须以后者为准。

### 4.3 保留集（泛化）

- 只在**最终模型冻结后**评一次；不得用保留集结果挑选检查点。
- 报告物理通过数 + 闭合分布，并注明"保留点与训练点在同一个局部区域"，不作整墙泛化声明。

---

## 5. 报告格式（剖面报告字段）

必填：

```
工况数 / 物理通过数 / 物理失败清单（含原因）
closure: mean / median / P95 / max
越 35 mrad 的工况数与清单
端点执行器误差: mean / max
躯干倾斜: mean / max
每个工况的: 分类、closure、抬升、端点误差、倾斜
```

分类枚举（实现见 `profile_eval.py`）：

| 分类 | 含义 |
|---|---|
| `pass` | 物理与姿态质量全部满足 |
| `physical_contact` | 非预期/摆动接触 |
| `physical_rise` | 抬升越限，且越限深度 > 1 mm（<1 mm 视为数值问题，归入 clamp 类） |
| `closure_over_old_line` | 物理通过，但闭合 > 40 mrad（仅报告） |
| `closure_over_warning` | 物理通过，闭合在 35–40 之间 |
| `endpoint_other` | 物理通过、闭合合格，但周期末判定失败（需查承载位置/接触） |
| `incomplete` | 未能跑完整周期 |

> **1 mm 死区**：跟踪误差本身就有 6 mm，抬升越限深度小于 1 mm 属于数值层面，不得计为物理失败
> （这条直接对应"不接受 0.02 mm 级噪声失败"的要求）。
