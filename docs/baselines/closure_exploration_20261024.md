# 2026-10-24：收尾阶段腿部探索方案

## 证据与假设

已选定策略的动作高斯标准差约为 0.05。实际动作范围为 ±1，残差目标幅度为 ±0.015 rad，每 20 ms 更新动作，每 5 ms 用 0.05 的系数更新残差。四次更新的等效保留系数为 0.95⁴。

在均值固定、动作噪声独立、滤波已达稳态的假设下，控制周期末参考扰动标准差为 0.015 × action_std × sqrt((1−0.95⁴)/(1+0.95⁴))。左踝对应约 0.239 mrad。这是参考输入的理论尺度，不是实测机器人关节运动，也不能单独证明探索不足。

待检验假设：仅在收尾阶段增大腿部采样方差，可以帮助发现更有用的闭合动作。该方案在正向质量奖励组评估完成之前不启动训练，不修改正在运行的实验。

## 实现与验证

`ClosureExplorationPolicy` 保持 148 维观测、26 维动作、原网络参数和优化器。直接读取原观测第 105 号（零起始）剩余时间分量；113.66 秒单周期中，从 99.66 秒开始，用三秒平滑过渡将前 12 个腿部动作的标准差乘四。其他动作及收尾前分布不变。

这不是修改环境动作上限，也不增加外力。确定性动作仍由同一动作均值产生；PPO 采样、log probability 与 entropy 统一使用改变后的状态条件分布。该类仅适用于目前冻结的周期长度与收尾时刻，协议准备器检查二者。

`closure_exploration_gate_20261024_v1` 已通过：

- 初始网络参数与优化器状态最大差为零。
- 收尾前标准差倍率为 1，过渡中为 2.5，过渡后腿部为 4；手臂一直为 1。
- 五工况所有保存观测逐条重算，确定性动作最大差均为零。
- 采样 log probability 与更新计算、手算正态分布一致；梯度有限。
- 保存并重载后，策略类型、参数和采样尺度保持一致。

上述是分布与保存观测重算检查，没有宣称第二次完整动力学复现。参考噪声理论标准差增至约 0.957 mrad，也不等于真实姿态改善。
