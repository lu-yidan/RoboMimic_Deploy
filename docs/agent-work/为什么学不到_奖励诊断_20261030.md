# 为什么三轮训练都只学到 0.4 mrad：奖励是常数（2026-10-30 夜间）

> 这条把"训练学不到东西"从现象变成机制，并且**依次否掉了三个猜测**：
> 观测被喂零（错）、动作空间不够大（部分对）、接触约束挡住了（对但不是主因）。
> **真正的原因是：每步奖励在收尾段几乎是一条平直线。**

---

## 一、直接测量：每步奖励的动态范围

取一次完整闭环（training_13）记录下来的奖励序列：

| 区段 | 步数 | 均值 | **标准差** |
|---|---|---|---|
| 全程 | 5,683 | 0.022830 | 0.265284（被末尾 +20 拉高） |
| **收尾段 71–111 s** | ~2,000 | **0.018482** | **0.000658** |
| 最后 2.66 s | 133 | 0.1700 | 1.7277 |

**收尾 40 秒里，每步奖励的变化范围只有 6.6e-4，是常数项 0.02 的 3.3%。**

奖励公式：

```python
error  = np.mean((q - q_ref)**2)                      # 平方！
reward = .02 - 2.*error - .001*mean(a**2) - .001*mean((a-a_prev)**2)
```

- `error` 是**平方**的：1° 跟踪误差（0.017 rad）→ `error = 3e-4` → 惩罚 **6e-4**，占常数项的 **3%**；
- 动作正则项量级 1e-4，可忽略；
- 唯一大信号是**终局**：成功 +20 / 失败 −20，以及终局裕量 ±6。

## 二、这为什么让 PPO 学不动

PPO 的探索是在动作空间加随机扰动。要让它往"更好的方向"走，扰动必须改变回报。

| 量 | 值 |
|---|---|
| 一步动作对 `error` 的影响 | ~1e-4 量级 |
| 对应奖励变化 | ~2e-4 |
| 整集回报 | ~130 |
| **单步信号 / 整集回报** | **~1.5e-6** |

再叠加上 `learning_rate = 3e-5`：131,072 步 = 约 128 次 rollout × 5 epoch = **640 次参数更新**。
这样的更新量只能让策略**缓慢漂移到一个常数偏移**——而这正是三轮训练都发生的事（+0.396 / +0.4 / 0）。

**结论：不是没有可学的东西，是奖励没有把可学的东西表达出来。**

## 三、配套的另一个测量：随机扰动被闭环吸收

在满权限残差上叠加 σ=0.015 rad 的随机噪声（收尾 42 秒），只换 4 个种子：

| 工况 | 4 个种子的闭合 | 标准差 |
|---|---|---|
| training_13 | 38.60 / 38.66 / 38.59 / 38.61 | 0.028 |
| training_14 | 38.63 / 38.74 / 38.68 / 38.70 | 0.040 |

**随机噪声只让闭合动 0.05 mrad（std），而系统性偏移能动 0.9–2.3 mrad。** 比例 1:20–1:45。

两件事合起来的图景：

> **这个闭环对"随机扰动"近似免疫，对"系统性偏移"近乎透明；
> 而奖励恰好把系统性方向的信息压缩成了 3% 的常数噪声。**
> 所以策略既没有梯度去发现方向，也没有信号去确认方向。

## 四、正在跑的验证实验（方案 A）

**只放大每步奖励的变化部分 50 倍，终局事件原样不动**：

```python
if abs(reward) < 1.0:                        # 稠密步
    reward = 0.02 + 50 * (reward - 0.02)
```

- 收尾段每步 std：0.000763 → **0.038126**（×50）
- 终局步（±20、±6）不变 → 通过/失败的判据不变
- 其余一切不变：同一 gate、同一父模型、1.25× 权限、131,072 步

**判据（事先定好）**：

| 结果 | 结论 |
|---|---|
| 闭合 mean 明显低于 37.905（比如 ≤37.0，即改进 ≥0.9 mrad） | **诊断成立**：奖励是瓶颈，RL 可以进入 |
| 仍在 37.9 附近（±0.3） | 奖励不是瓶颈，转查探索/学习率（`lr` 从 3e-5 提到 3e-4） |
| 变差或训练不稳（早期大量终止） | 放大过头，改 10× 再试 |
