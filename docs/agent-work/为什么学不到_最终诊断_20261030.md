# 为什么学不到：完整证据链（2026-10-30 夜间）

> 目标：让"训练有没有用"这句话成立，并找出进入 RL 阶段前必须修的东西。
> 今晚依次否掉了三个猜测，最后落到一个**可以量化、可以修**的地方。

---

## 一、证据链（按时间顺序）

| # | 假设 | 检验 | 结果 | 判定 |
|---|---|---|---|---|
| 1 | 策略看不见杆位（观测被喂零） | 查 manifest 的 `geometry_mode` + `geometry_projection` 权重 | 三个 manifest **都是 oracle**；投影是 (136,12)、**272 非零（2 列）**、max\|w\|=0.022 | ❌ **否掉**：看到的，只是弱 |
| 2 | 我的 oracle 实验能对比"看得见 vs 看不见" | 加载两个 checkpoint 比权重 | **权重逐张量完全相同**（max\|Δw\|=0） | ❌ **作废**：补丁是空操作，自己和自己比 |
| 3 | 随机探索有足够梯度 | 满权限（σ=0.015 rad）噪声 4 个种子 | 闭合 std **0.05 mrad**（系统性偏移可达 0.9–2.3） | ⚠️ 探索几乎被闭环吸收 |
| 4 | 奖励太"平"，放大即可 | 只放大稠密项 50×，重训 131k 步 | **mean 38.001** vs 37.905（略差），P95/max 同样略差 | ❌ **否掉**：奖励不是瓶颈 |
| 5 | **策略其实没怎么动** | 比 `\|\|Δw\|\|/\|\|w\|\|`（相对父模型） | **0.166%**（max\|Δw\|=0.0057，权重均值 0.097） | ✅ **成立** |

## 二、第 5 条才是根因

131,072 步、约 640 次参数更新之后：

```
parent -> rewardx50    ||Δw||/||w|| = 0.1658%
parent -> blind 1.25x  ||Δw||/||w|| = 0.1953%
```

**策略相对父模型只移动了千分之二。** 它基本没动。

这解释了三轮训练为什么都落在 0.4 mrad 附近：不是"找不到方向"，是**步子太小**。
对应的两个超参：

| 超参 | 现值 | 说明 |
|---|---|---|
| `learning_rate` | **3e-5** | 131k 步总共约 640 次更新，累计步长极小 |
| `target_kl` | **0.01** | 每轮更新被信任域卡得很死 |

## 三、正在跑的验证（最后一个未测杠杆）

**同一 gate、同一父模型、1.25× 权限、131,072 步**，只把
`lr: 3e-5 → 3e-4`、`target_kl: 0.01 → 0.05`。

> 注：训练器在 `learn()` **之前**断言超参与父 manifest 一致，所以这个覆盖不会触发断言；
> 但该 run 的 manifest 会记录父模型的超参，**引用时必须注明这一点**。

**判据（事先定好）**：

| 结果 | 结论 |
|---|---|
| 闭合 mean ≤ 37.0（改进 ≥0.9 mrad），且 `\|\|Δw\|\|/\|\|w\|\|` 显著大于 0.2% | **诊断成立**：优化预算不够，RL 可以进入（再把 lr/KL 调到合适值即可） |
| 闭合仍 37.9±0.3，但权重移动明显变大 | 步子够了但方向不对 → 转向低维动作空间（只放开膝/踝 2–4 维） |
| 训练不稳/早期大量终止 | 步子太大 → 取 5e-5 / 3e-4 之间 |

产物：`outputs/calibrated_geometry_ppo131072_20261030_lr10x_v1`，自动评估挂在
`.dsh-watch/wait_eval2.log`，结果在 `.dsh-watch/lr10x_all24/`。
