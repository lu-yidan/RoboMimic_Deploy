# 决定性结果：动作空间诊断成立，但奖励方向是反的（2026-10-30 18:22）

## 一、结果：2 维动作空间让训练第一次真正改变了闭合 —— 但是往坏的方向

24 工况，与 blind 1.25× 对比：

| 组 | mean | P95 | max | 失败数 |
|---|---|---|---|---|
| 冻结 1.0× | 38.115 | 39.852 | 40.092 | 0 |
| 冻结 1.25×（base） | 37.905 | 38.800 | 38.844 | 0 |
| lr×10（26 维） | 37.858 | 38.689 | 38.742 | 0 |
| **mask{3,4}（2 维）** | **44.637** | **47.612** | **47.840** | **22/24** |

逐工况几乎**一致地变差 +6.7 ~ +9.0 mrad**（闭合集中在 45.2–47.8，非常均匀）。

## 二、这是什么意思

**这是四轮训练里第一次训练实质性改变了闭合**（−0.05 / +0.1 / −0.05 → **+6.7**）。
说明"动作空间里没有杠杆"这个判断**对了一半**：

- **26 维**：没有杠杆 → 训练再怎么改也只值 0.05–0.4 mrad；
- **2 维**：**有杠杆，而且很大** → 训练一动手就动了 6.7 mrad。

但它动反了。原因是最直接的：

> **训练奖励的主项是"关节跟踪误差"，而评估指标是"端点闭合"。**
> 在 2 维子空间里，PPO 能轻松优化前者，而前者的最优点恰好让后者变差。

证据链一致：奖励放大 50× → 略差（+0.1）；2 维放开 → 大幅变差（+6.7）。
**放大一个方向错的奖励，只会让错得更彻底。**

## 三、修正之前的判断

| 之前说 | 更正 |
|---|---|
| "奖励不是瓶颈"（×50 无改善） | **错**。奖励的**方向**是瓶颈，不是它的幅度。放大无效恰恰因为方向错 |
| "动作空间没有高杠杆方向" | **只对 26 维成立**。2 维有杠杆（6.7 mrad） |
| "残差层已到底" | **不成立**。2 维一放开就动了 6.7 mrad，说明空间够用 |

## 四、下一步（方向已明确）

**保持 2–4 维动作空间，把奖励换成就等于评估指标的量。**

具体：把每步/终局的奖励项从 `mean((q − q_ref)²)` 换成**端点闭合的代理量**
（例如 `−|q_endpoint − q_start|` 的逐步平滑版本，或 `−|foot_error|`、`−|base_error|`）。

理由链条：
1. 评估指标 = 端点闭合；
2. 26 维下策略够不着它（杠杆 0.05）；
3. 2 维下够得着了（杠杆 6.7），但奖励指错方向；
4. 所以只需要**把奖励指向同一个量**。

预期：若成立，闭合应显著低于 37.905（因为 2 维的可达范围本身就是 2.3 mrad 量级，而现在我们知道它实际能动 6.7）。
