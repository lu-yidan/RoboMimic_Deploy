## 3. 为什么说 40 mrad 是拟合的（1 分钟）

**讲**：这条线的来历是"0.038 过、0.0402 不过"，没有任何物理推导；而 8 周期里最差的那个角刚好 39.898。

```powershell
Select-String -Path docs\baselines\compact_gait_20261009.md -Pattern '0\.03813|0\.04016' |
  ForEach-Object { "L$($_.LineNumber): " + (@([regex]::Matches($_.Line,'0\.0\d{3,5} rad') |
    ForEach-Object { $_.Value }) -join ' / ') }
```

预期（三行，说明当时的判定就是"0.038 过、0.0402 不过"）：

```
L20: 0.01706 rad / 0.03813 rad
L42: 0.03813 rad
L53: 0.04016 rad
```

## 5. 审计链：一句话证明"这个目录没被改过"（2 秒）

**讲**：每个实验目录都记录了全部源码的 sha256，任何人可以验证。

```powershell
& $py "$watch\check_sources.py" outputs\calibrated_geometry_training_baseline_20261027_v1
```

预期：

```
[enforced] training/ mismatches: 0
[provenance only] tools/ mismatches: 1
    CHANGED tools\train_calibrated_landing.py
verdict: reproducible (training sources unchanged)
```

**这个输出本身就是最好的教学材料**：`training/` 是审计强制的，`tools/` 只做溯源——所以
"改了工具不会破坏旧实验的可复现性，但改了 `training/` 就会"。我们这个改动正好演示了这条边界。

## 常见报错

| 现象 | 原因 | 解决 |
|---|---|---|
| `UnicodeEncodeError: 'cp950' codec` | 控制台编码 | `$env:PYTHONIOENCODING = 'utf-8'` |
| `FileExistsError` | 输出目录已存在 | 换个名字或先删 |
| `AssertionError: Gate failed` | 门槛没过（奖励重建不一致） | 先跑 `check_calibrated_landing` 单独看日志 |
| `找不到 tools.xxx` | 不在仓库根目录 | `cd D:\G1Climbing\external\RoboMimic_Deploy` |
