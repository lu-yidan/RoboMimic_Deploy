# 接触重锚定（contact re-anchoring）设计（2026-10-29）

> 起因：上机检查 3b 测出**落点偏 2.7 mm 就让闭环失败**（闭合 38.6 → 42–46），偏 5.5 mm 直接崩到 63。
> 结论是参考不能"以计划为准"地走完，必须"以接触为准"。这份是具体做法。

---

## 一、要先说清楚它**不**解决什么

有个陷阱必须先讲：**重锚定不会让闭合指标变好，反而会让它变差。**

因为闭合 = `|q_终点 − q_起点|`，如果落点偏了 2.7 mm 而我们接受这个现实、把后续参考移过去，
那终点也会跟着移 2.7 mm，闭合照样变大。

**但这不是失败。** 闭合是"仿真里相对初始位姿的姿态偏移"；真机上关心的是：
- 有没有摔倒
- 有没有落在预期的杆上
- 抬升够不够 250 mm
- 有没有非预期接触/关节超限

所以：

> **重锚定解决的是"可行性"，不是"闭合指标"。**
> 到了真机，验收口径必须换成相对**实际接触构型**的判据，而不是相对仿真初始位姿的闭合。

这一条本身值得写进论文——它说明"用单周期闭合当验收"在跨域时会失效。

## 二、要做什么

在**检测到落地接触的那一刻**，用实际落点重算"剩余参考应该长什么样"，让后面的动作从真实构型继续。

```
t < t_land :  照原参考走
t = t_land :  检测到接触 → 算实际落点与计划落点的偏差 → 反解关节修正 Δq
t > t_land :  q_ref(t) ← q_ref(t) + w(t)·Δq     （w 平滑过渡，1–2 s 内从 0 到 1）
```

Δq 用阻尼最小二乘从脚位误差反解（6 个腿部关节，3 维位置目标，留出冗余给姿态）。

## 三、实现挂钩点（精确到函数）

不需要动仓库代码，运行时包装即可：

| 挂钩 | 位置 | 作用 |
|---|---|---|
| `FullCycleResidualEnv.reference(t)` | `training/full_cycle_residual_env.py:69` | 返回插值后的参考 q；在这里加 `Δq·w(t)` |
| `FullCycleResidualEnv.reset(...)` | 同文件 94 | 每个 episode 清零 Δq 与"已锚定"标志 |
| 接触检测 | `physical.contact_metrics()` | 已有分组支撑力，直接用（脚组竖直力 > 阈值即接触） |

伪代码：

```python
def reference_with_anchor(self, t):
    q, v, active, phase = original(self, t)
    if t < LAND:                      # LAND 从 plan 里读（左脚踏杆时刻 81.46 s）
        return q, v, active, phase
    if self._anchor is None:          # 第一次越过落地时刻：此刻 d.qpos 就是真实落点
        error = planned_foot_pos(LAND) - actual_foot_pos(self.env.data.qpos)
        self._anchor = solve_leg_delta(error)      # 加权阻尼最小二乘
    w = smoothstep((t - LAND) / RAMP)
    q = q.copy()
    q[self.e.qadr[LEG]] += w * self._anchor
    return q, v, active, phase
```

注意：**必须用 `d.qpos`（真实状态）而不是参考**来算偏差，否则永远是 0。

## 四、验证方式

| 实验 | 期望 |
|---|---|
| 无重锚定 + 落点偏 2.7 mm（已做） | 失败，闭合 42–46 |
| **有重锚定 + 落点偏 2.7 / 5.5 mm** | **不摔、不超限、落在预期杆上**；闭合可能仍偏大（见第一节） |
| 有重锚定 + 无偏差 | 与基线逐位一致（回归检查，必须做） |

判据用"物理判据"（接触/关节/抬升），不用闭合。这一套 `profile_eval.py` 已经实现。

## 五、工作量与风险

- **实现**：半天（含回归检查）。
- **风险 1**：Δq 只在落地瞬间算一次，若之后接触点变化（脚在杆上滑），锚定会失效 → 需要按周期重算或持续更新。
- **风险 2**：锚定把姿态也一并移了，可能让后续摆动变窄 → 需要检查重锚定后各段的间隙是否仍 >0。
- **风险 3**：真机上接触检测有延迟（F/T 滤波 ~5–20 ms），落地判定的时刻会晚，Δq 要按延迟后的构型算。

## 六、对十二月的意义

如果这个原型在仿真里成立（2.7–5.5 mm 偏差下仍物理可行），那十二月的路径就清楚了：
**换落地方式 → 仿真验证 → 上机**，而不需要重训策略、不需要换 WBC。

如果不成立，说明"参考 + 残差"这套架构对世界模型的精度依赖过强，真机上要换成
"接触一致的运动生成"，那是另一个量级的工程。
