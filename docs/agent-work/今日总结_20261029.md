## 二、训练为什么学不到东西（今天的主结论）

三次训练（v1、v2、1.25×）都得到同一个结果，今天终于能给出**机制解释**而不是猜测：

| 实验 | 结果 | 含义 |
|---|---|---|
| 1.25× 权限重训 131,072 步 | mean 37.905，相对"只改常量"的 37.920 **只差 0.015** | 训练增量是噪声级 |
| 分布重塑模式 | 高闭合降、低闭合升，**与冻结策略完全一致** | 没学会"选择性使用权限" |
| 力通道消融（置零/加噪/冻结） | 闭合变化 ≤0.16 mrad | 策略**不看**接触力 |
| T8（手杆几何投影） | 精确为零 | 策略**看不见**杆位 |

> **一个看不见杆位、感觉不到接触的策略，只能吐出一个常数偏移。**
> 瓶颈不是动作空间（1.25× 证明有空间、1.5× 证明是上限），不是奖励形状（v2 + 1.25× 都没增量），
> **而是策略没有可条件化的输入**。

**唯一剩下的杠杆：T10 感知→动作通路。**

### 注意：T10 的验证方式要选对

"把观测切成 oracle 档、用冻结策略跑 24 工况"**证明不了任何东西**——冻结策略是按盲档训练的，给了它也不会看。
真正的实验是：**用 oracle 观测做一次短程微调**（32k 步 ≈ 40 分钟），看被位移的工况是否开始下降。
如果 32k 步内看不出方向，说明这条通路即使打开也不够，那就得重新考虑整个"参考+残差"架构。

由此两条路线：
- **A. 力矩接口 + 接触估计**：LowCmd 发 `tau`（kp=kd=0），接触点用"预期杆位 + FK 最近点"（几毫米够用）。

  浮动基机器人必须有接触力层，`PD` 只能控制关节相对姿态，托不住机身。

**所以十二月的工作量在控制层，不在学习层。**
