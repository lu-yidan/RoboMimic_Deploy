## 卡住的（一个指标）

**`surv = 0.000`**（想象轨迹存活率）从头到尾没动过，`imag_ret` 在 0.345 处平台。

含义：策略活不过想象窗口，BPTT 拿不到长程梯度，回报上不去。

## 三个假设，两个已被数据否掉

| 假设 | 检验 | 结果 |
|---|---|---|
| 片段太长（113 s vs 其 5.8 s 中位） | 缩到 43 s 重训 | ❌ 否掉：`surv` 仍 0.000，`imag_ret` 0.345→0.346 |
| 刚体不足（1 vs 30） | 补到 33 刚体重训 | ❌ 否掉：指标逐位相同。原因：紧凑库只存**根+关节**，其余刚体由 online FK 算 |
| **关节顺序不匹配** | **未验证** | 待查 |

## 第三个假设的根据（代码级）

```python
# commands.py:53
default_joint_pos = self.robot.data.default_joint_pos[0]   # 来自 mjlab 的 G1 资产
self.body_indexes = self.robot.find_bodies(cfg.body_names, preserve_order=True)[0]
```

即：**刚体按名字查（已确认全覆盖），但关节是按下标用的**。我们紧凑库里的 `joint_pos(29)`
用的是**我们自己 MuJoCo 模型的关节顺序**；mjlab 的 G1 若顺序不同，online FK 算出的姿态就是错的
→ 跟踪目标是垃圾 → 策略永远学不会。

## 为什么需要一个对照实验才能继续

要区分"我们数据接错了"和"环境本身跑不动"，唯一干净的办法是**跑他们自带的 LAFAN 小样**：

- 若 LAFAN 小样能训出 `surv > 0.5` → 环境没问题，是我们的数据/顺序错 → 继续修转换
- 若 LAFAN 也跑不动 → 是环境差异（mjlab 版本、资产、reward 配置）→ 这条线要重新评估

**但仓库里没有任何样例动作数据**（`data/` 下只有 site-packages），需要另行下载 LAFAN1 或
从 release 的 checkpoint 反推，成本不低。

## 我的建议

按"只要做出来就行"这个标准，**SuperMimic 这条线目前的性价比已经不划算**：

- 已投入：环境 3 次踩坑 + 3 次根因假设（2 次被否）
- 未解决：关节顺序 + 可能的资产差异
- 而它要解决的问题（23 mrad 结构性下垂）**不影响系统能不能用**——24/24 物理通过、8 周期 2 米

**十二月的真正阻塞是控制层可移植性**（部署栈吃 `q_des+kp+kd`，我们的控制器要 `d.contact`）。
这条不解决，SuperMimic 训得再好也上不了机。

**建议**：SuperMimic 线暂缓，除非愿意花半天做 LAFAN 对照实验。主力转回控制层。
