# 动作空间降维：设计（2026-10-30）

> 依据：昨晚三条独立证据表明 **26 维残差里没有高杠杆方向**，而低维（2–4 维）偏移能给出 0.85–2.3 mrad。
> 这份给出具体的降维方案、实现方式和判据，可直接执行。

---

## 一、证据回顾（为什么降维）

| 动作变化 | 对闭合的影响 |
|---|---|
| 26 维随机噪声（满权限 σ=0.015 rad） | 0.05 mrad |
| 26 维系统性训练（三组，最大移动 0.985%） | 0.05–0.4 mrad |
| 2 维固定偏移（膝/踝，校准偏置 0→1.0） | **2.3 mrad** |
| 权限常量 1.0→1.25×（等效 2 维） | **0.85 mrad** |

**同样的"改动量"，2 维方向的效力是 26 维的 5–45 倍。**

## 二、选哪几维

从动作索引（26 维，对应 `e.indices` 的关节顺序）看，历史证据指向这 4 个：

| 维 | 关节 | 依据 |
|---|---|---|
| **3** | left_knee | 校准偏置就用它（−0.5 归一化） |
| **4** | left_ankle_pitch | 同上 |
| 加 1 | 腰部前倾（waist pitch） | 影响重心位置 |
| 加 2 | 抬升高度 / 身体前移 | 影响落脚几何 |

**建议第一版只放开 {3, 4}**，与校准偏置同维——这样它至多能学成"自适应版校准偏置"，
可以**直接与固定偏置对比**，结论最干净。

第二版再加腰部与抬升，放到 4–6 维。

## 三、实现（不改仓库代码）

在 `sitecustomize` 里加一个动作掩码，只在需要时启用：

```python
# .dsh-watch/wide/action_mask_override.py
def install(active=(3, 4)):
    import numpy as np
    from training.full_cycle_residual_env import FullCycleResidualEnv as cls
    mask = np.zeros(26)
    mask[list(active)] = 1.0
    original = cls.step
    def step_masked(self, action):
        return original(self, (np.asarray(action, float) * mask).astype(np.float32))
    cls.step = step_masked
```

用环境变量 `G1_ACTION_MASK=3,4` 启用。

> 注意：观测里仍保留 26 维残差通道（值恒为 0 的那 24 维），不需要改观测接口。

## 四、实验与判据

**同 gate、同父模型、1.25× 权限、131,072 步、`lr=3e-4`、`target_kl=0.05`**（用昨晚已验证能推动策略的那套），
只加动作掩码 `{3,4}`。

| 结果 | 结论 |
|---|---|
| mean ≤ 37.0（改进 ≥0.9 mrad），且低闭合工况**不再被抬高** | **诊断成立**：低维动作空间让训练真正有效 → RL 可以进入 |
| mean 37.9±0.3（与这次一样） | 说明即使低维也没用 → 瓶颈不在参数化，而在**参考/控制器层**（即那 10 mrad 的结构性下垂） |
| 训练不稳 | 加大掩码维度或降 lr |

**参照**：frozen 1.0× = 38.115 / blind 1.25× = 37.905 / lr10x = 37.858。

## 六、如果这条也不行

那就说明**残差这一层已经没有可挖掘的量了**，10 mrad 的结构性下垂只能靠：
- 换控制器结构（WBC：加速度为决策变量、接触力为约束）；
- 或让参考本身可学（学参考的自由参数，而不是学残差）。

这两条都超出"训练一个 PPO"的范围，属于架构级改动。
